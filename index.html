ESP32-S3 Telegram Bot

Remote IoT Control straight from your favourite messaging app

About the Project

This project bridges the gap between hardware and the cloud by turning an ESP32-S3 microcontroller into a smart Telegram Bot. Without writing a single line of app code, you get a beautiful, cross-platform interface to control your hardware from anywhere in the world.

Key Features

  • Global Control: Uses the Telegram API to bypass home routers and firewalls. Control your board over 4G/5G.
  • Hardware Integration: Uses standard digital I/O to control the ESP32-S3 LED on Pin 2.
  • Secure Access: Implements Chat ID verification so the bot only responds to you, ignoring unauthorised users.
  • Custom Keyboards: Features an interactive reply keyboard on Telegram for quick, button-based commands instead of manual typing.
